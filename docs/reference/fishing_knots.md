# Fishing Knots (Field Card)

Three knots cover most of what I fish: **Uni** for tying to terminal tackle, **Uni Snell** for straight-line pull on bait hooks, and **Alberto** for joining braid to a mono/fluoro leader. Wet every knot before cinching. Diagrams: John E. Sherry / netknots.com.

---

## Uni Knot
*Line → hook, swivel, or lure. The everyday terminal knot.*

<div markdown style="display:flex; gap:1em; align-items:flex-start; flex-wrap:wrap;">
<img src="img/uni_knot.jpg" alt="Uni Knot diagram" width="230">
<div markdown>
1. Run line through the eye and double it back parallel to the standing line.
2. Lay the tag over the doubled line to form a loop.
3. Wrap the tag through the loop and around the double line **5–6 times**.
4. Wet it, pull the tag to snug the coils, then slide the knot down to the eye.
</div>
</div>

## Uni Snell Knot
*Line → hook shank. Even, straight-line pull for bait hooks (best with up-eye or ringed hooks).*

<div markdown style="display:flex; gap:1em; align-items:flex-start; flex-wrap:wrap;">
<img src="img/uni_snell_knot.jpg" alt="Uni Snell Knot diagram" width="230">
<div markdown>
1. Run the line through the eye and down the shank; form a loop alongside the shank.
2. Pass the tag around the shank and through the loop **4–6 times**, keeping wraps tight together.
3. Work the coils down toward the eye.
4. Wet it, then pull the tag and standing line apart to seat the knot.
</div>
</div>

## Alberto Knot
*Braid → mono/fluoro leader. Slim line-to-line join that runs through guides.*

<div markdown style="display:flex; gap:1em; align-items:flex-start; flex-wrap:wrap;">
<img src="img/alberto_knot.jpg" alt="Alberto Knot diagram" width="230">
<div markdown>
1. Fold a loop in the leader; pass ~10" of braid through it.
2. Wrap the braid around both leader strands **7 times** away from the loop.
3. Wrap **7 times** back toward the loop, over the first wraps.
4. Feed the tag back through the loop, exiting where it entered.
5. Wet it, snug the wraps down to the loop's end, then trim both tags close.
</div>
</div>
